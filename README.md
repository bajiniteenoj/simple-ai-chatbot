# Simple AI Chatbot 🤖

This is a beginner-friendly AI chatbot built using Python.

## Features
- Responds to greetings like hello
- Answers simple questions
- Runs in terminal
- Easy to understand and modify

## Technologies Used
- Python

## How to Run

1. Install Python
2. Download the project
3. Run:

python chatbot.py
